## 评审修复（2026-09-08）

### 修复内容

- 修正算力口径：实际算力结构条仅由自建与租赁两个互斥部分组成，分母采用实际算力。
- 昇腾规模不再加入结构条，改为独立“昇腾覆盖实际算力”进度条，分母采用实际算力。
- 增加实际算力为零时覆盖率归零处理，避免除零和无效进度值。
- `base-002` 现在明确展示：自建 210P + 租赁 130P = 实际算力 340P；昇腾 260P / 340P = 76.5% 覆盖率。
- 收入完成率统一保留一位小数，`base-002` 展示为 46.7%。
- 原“将三类算力并列堆叠”的顾虑已解决，不再产生 600P/340P 或 1100P/620P 的错误表达。
