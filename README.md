# AI中试基地看板平台

面向AI项目组的中试基地/平台看板系统，用于集中查看基地的基础信息、经营信息、三大关键活动以及政策/行业/产业动态，辅助管理层了解中试基地的发展现状并支撑经营决策。

## 功能模块

- **看板总览**：基地总数、批复情况、华为标杆数量、建设金额、算力规模、昇腾规模、年度收入等关键指标汇总，以及全部基地的现状列表。
- **基础信息**：按基地维度展示批次、行业、部委、申报方向、地域、批复状态、申报/承接/运营单位、是否华为标杆及标杆级别、生态及合作伙伴（含合作方面与七类伙伴归属）、基地规模（建设金额、规划算力规模，含自建/租赁拆分），并可跳转至对应基地的经营信息查看昇腾规模。
- **经营信息**：按基地维度展示关联机会点、项目级别、客户级别、预计收入（年度，含昇腾建设份额与金额）、已完成订货/收入（累计与年度、区分产品）、预期剩余收入（自动计算）、实际算力规模及自建/租赁/昇腾规模拆分。
- **三大关键活动**：
  - 场景：场景全景图，可筛选华为及华为伙伴参与的重点场景，展示场景引入的伙伴。
  - 中试平台：基于参考架构（AKDI/DIMAK）展示客户已完成情况与华为参与情况。
  - 关键生态活动：启动会、生态联结会、成果发布、大会发布等动态。
- **政策/行业动态**：按政策动态、行业动态、产业动态分类展示最新资讯，支持分类筛选。

## 技术栈

- [Vite](https://vite.dev/) + React 19 + TypeScript
- [Vitest](https://vitest.dev/) + [Testing Library](https://testing-library.com/) 用于单元与组件测试
- [oxlint](https://oxc.rs/) 用于静态检查

当前数据来源于内置的模拟数据（`src/data/mockData.ts`），后续可替换为真实的后端数据接口。

## 常用命令

```bash
npm install       # 安装依赖
npm run dev       # 启动开发服务器
npm run build     # 类型检查 + 生产构建
npm run test      # 运行测试
npm run lint      # 静态检查
npm run preview   # 预览生产构建
```
