# AI中试基地看板平台

面向 AI 项目组的中试基地/平台看板高保真交互演示版，用于集中查看基地的基础信息、经营信息、三大关键活动以及政策/行业/产业动态，辅助管理层了解中试基地的发展现状并支撑经营决策。

## 功能模块

- **看板总览**：基地总数、批复情况、华为标杆数量、建设金额、算力规模、昇腾规模、年度收入等关键指标汇总，以及全部基地的现状列表。
- **基础信息**：支持按关键字搜索、批复状态和行业组合筛选基地；按基地维度展示组织、规模与生态伙伴信息，并可下钻至对应基地的经营信息。
- **经营信息**：支持基地经营下钻与基地切换，展示关联机会点、收入完成度、订货/收入结构及自建、租赁、昇腾算力投入。
- **三大关键活动**：
  - 支持在场景全景、中试平台和关键生态活动间切换。
  - 场景视图可筛选华为及华为伙伴参与的重点场景；平台视图展示参考架构建设情况；活动视图展示启动、联结与成果发布动态。
- **政策/行业动态**：按政策动态、行业动态、产业动态分类展示最新资讯并支持分类筛选。
- **响应式支持**：适配桌面与移动端布局，移动端导航可横向访问，指标、筛选栏和图表按屏幕宽度自动重排。

## 技术栈

- [Vite](https://vite.dev/) + React 19 + TypeScript
- [Vitest](https://vitest.dev/) + [Testing Library](https://testing-library.com/) 用于单元与组件测试
- [oxlint](https://oxc.rs/) 用于静态检查

当前演示版仍使用内置模拟数据（`src/data/mockData.ts`），尚未接入真实后端数据接口。

## 常用命令

```bash
npm install       # 安装依赖
npm run dev       # 启动开发服务器
npm run build     # 类型检查 + 生产构建
npm run test      # 运行测试
npm run lint      # 静态检查
npm run preview   # 预览生产构建
```
